# BlindSpot AI (Client & API App)

An AI-powered decision reflection tool built to challenge assumptions and support human critical thinking.

## Setup Instructions

1. `npm install`
2. Create `.env.local` and add `GEMINI_API_KEY=your_key_here`
3. `npm run dev` to start locally
4. `npm run build` to build for production
5. Deploy to Vercel
